# Install Vocab-track

You need Chrome 116 or later on a computer (Windows, macOS, Linux or
ChromeOS). It does not run on phones.

1. Open STORE_URL.
2. Click **Add to Chrome**, then **Add extension** in the box that appears.
3. Click the puzzle-piece icon at the right of the address bar, then the pin
   next to **Vocab-track**. Its icon now stays in the toolbar: click it to open
   or close the side panel.
4. On any English article, select a word and click the 📘 button that appears
   under it. The side panel shows the word and saves it with its sentence.

Your saved words are in the dashboard: click **Open dashboard →** at the top of
the side panel.

Updates are automatic. Chrome installs new versions on its own.

## Moving from a developer install

If you ran Vocab-track from a downloaded folder before, the store version is a
separate extension and starts empty. To bring your words across:

1. In the old one, open the dashboard → **Import & export** → **Export JSON**.
2. Remove the old one: right-click its toolbar icon → **Remove from Chrome**.
3. Install the store version as above, open its dashboard → **Import &
   export**, and under **Import** choose the file you saved. Review schedules
   and folders come with it.

Settings are not part of an export, a GIPHY key included: set them again.
